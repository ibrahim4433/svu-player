About SVU Player

SVU Player — Studio Edition

Version v2.8.1

High-performance local & offline session player engineered for Syrian Virtual University (.lrec) recordings.

100% Local & Offline Ready Zero External Tracking ibrahim4433/svu-player
WASM Decoder & 4-Stage Vocal DSP

Hardware-accelerated screen replay paired with a 4-stage speech processor (high-pass filter, +5.5 dB vocal presence EQ, smooth noise gate, and soft-knee compressor).

9 Studio Themes & Smart Metadata

9 built-in themes (Default, WhatsApp, Telegram, Win98, WinXP, Win7, Hacker, VS Code, Terminal) + Dark/Light mode & automatic .lrec filename tag parsing.

IndexedDB Offline Library & PWA

Save downloaded recordings directly inside your browser and install SVU Player as a standalone offline app.

Full Offline Deployment (PWA App)

Install SVU Player on your desktop or phone so it launches instantly without a browser bar and works 100% offline with local .lrec files and saved sessions.

If the browser prompt does not appear automatically, click the Install App icon (⊕) in your browser's address bar.

Local Server Deployment (Online SVU Catalog & Downloads)
Local Server & Developer Setup ▾

To browse the live SVU session catalog and download .lrec files directly from sessions.svuonline.org, run the local server in your project directory:

1. Install Python (if needed) Download Python 3 from python.org. On Windows, make sure to check 'Add python.exe to PATH' during installation.
2. Clone or Download Repository Clone via Git or download & extract the ZIP file from GitHub:
git clone https://github.com/ibrahim4433/svu-player.git
3. Open Folder & Run Server Open your terminal in the svu-player folder and start the local server:
python serve.py   # Windows  |  python3 serve.py  (Mac/Linux)
4. Open Browser Visit http://localhost:8080/ to explore and download university sessions without limits.

٤ طرق لتشغيل وحفظ محاضرات الجامعة الافتراضية

سواء أردت تشغيل محاضرة واحدة مباشرة، تنزيل مقرر كامل بأمان، المشاهدة دون إنترنت، أو فتح ملف جاهز على جهازك:

جلسات الجامعة (SVU sessions) تشغيل أو حفظ أونلاين

اختر الفصل (TERM) ← البرنامج (PROGRAM) ← المادة (COURSE) ← المدرس (TUTOR) ← الشعبة (CLASS) ← الجلسة (SESSION).

تنزيل المواد (Batch download) تنزيل مقرر كامل

اختر TERM و PROGRAM، اضغط على المادة لعرض المدرس والشعبة، حدد المحاضرات المطلوبة، ثم اضغط تنزيل بأمان.

مكتبة الطالب (Student library) ١٠٠٪ أوفلاين

استعرض جميع تسجيلاتك المحفوظة دون استهلاك إنترنت، صفِّ حسب المحاضرات المشاهدة ✓، أو تحقق من توفر محاضرات جديدة.

فتح ملف / التجربة الفورية ملف .lrec أو تجريبي

لديك ملف محاضرة .lrec من التيليجرام أو LMS؟ افتحه فوراً، أو جرّب المحاضرة النموذجية لاختبار مزايا المشغل الآن.

مصمم لظروف الشبكة في سوريا: جميع الملفات المحفوظة تخزن بأمان محلياً (IndexedDB) وتعمل بكفاءة كاملة دون استهلاك أي رصيد بيانات.

توضيح صوت الدكتور بأعلى نقاء بضغطة زر

هل تعاني من انخفاض صوت الدكتور، صدى القاعة، أو أزيز المايك؟ اضغط زر Enhance في شريط التحكم لتصفية نبرة الصوت فوراً وسماع الشرح بنقاء مريح للمذاكرة.

كيف يعمل المعالج تقنياً (٤ مراحل معالجة DSP):
1
بوابة كتم الضجيج (Noise Gate) عزل الصفير والهمس أثناء فترات الصمت
2
فلتر قص الترددات (High-Pass) قص ترددات هواء القاعة وأزيز التكييف
3
موازن نبرة الصوت (Vocal EQ) تضخيم نبرة صوت المدرس (1-4 kHz) ليصبح واضحاً
4
محدد الذروة السريع (Peak Limiter) حماية من التشويه والفرقعات الصوتية المفاجئة
متى تستخدم فلتر الصوت؟ فعّله في المحاضرات ذات التسجيل الضعيف أو صدى القاعة لرفع وضوح مخارج الحروف فوراً.

أهم الأسئلة الشائعة والحلول السريعة للطلاب

إجابات مباشرة على أكثر استفسارات الطلاب تكراراً حول التنزيل، ذاكرة المتصفح، والنسخ الاحتياطي:

لماذا زر «تنزيل المحاضرات المحددة بأمان» غير مفعّل (رمادي)؟

في التنزيل المجمّع، يجب أولاً اختيار الفصل (TERM) والبرنامج (PROGRAM)، ثم الضغط على سطر المادة لعرض مدرسيها وشعبها، وتحديد مربع اختيار محاضرة واحدة على الأقل. يتفعّل الزر تلقائياً فور تحديد المحاضرات.

هل يؤدي مسح بيانات المتصفح لحذف المحاضرات المحفوظة؟

نعم. المحاضرات أوفلاين تُحفظ داخل ذاكرة المتصفح (IndexedDB). إذا مسحت بيانات المواقع أو غيّرت جهازك فستُحذف. قبل مسح البيانات، افتح القائمة السريعة (☰) واضغط تصدير نسخة (Export Backup) لحفظ مقرراتك في ملف آمن على جهازك.

كيف أشغّل محاضرة باستخدام رابط مباشر من الجامعة؟

لديك رابط محاضرة مباشر من الـ LMS أو البريد؟ اضغط جلسات الجامعة من الشاشة الرئيسية، ثم اختر تبويب الرابط المباشر (Direct link) في أعلى النافذة، والصق الرابط للتشغيل أو الحفظ فوراً.
